# v1.1：多轮会话 / MCP / LLM 降级 / 异步入库（2026-11-09）

## 1. 多轮会话（feat/session）
- `src/ragm/conversation/store.py`：SQLite（WAL、busy_timeout、每操作独立连接）；sessions/messages；历史按 6 轮 / 4000 字截断；
- `src/ragm/conversation/rewrite.py`：一次 `chat(json_mode=True)` 做指代消解 + 子问题拆解；坏 JSON/异常回退原文；
- `rag/graph.py::_retrieve_node`：子问题 ≥2 时逐条检索、按 chunk_id 去重；
- API：`POST/GET/DELETE /api/sessions`；`/api/query(|/stream)` 支持 `session_id`，响应带 `rewritten_question`/`subquestions`/`session_id`。

## 2. MCP 工具（feat/mcp）
- `src/ragm/mcp/server.py`：MCPServer 三工具 `list_dir`/`read_file`/`write_note`，沙箱根内路径校验；
- `src/ragm/mcp/client.py`：每次调用起 stdio 子进程（`sys.executable -m ragm.mcp.server`）；
- `src/ragm/mcp/confirmation.py`：HMAC token（tool+args+exp）、TTL 60s、原子单次消费、墓碑防重放；410/409/404；
- API：`GET /api/mcp/tools`、`POST /api/mcp/call`（敏感工具 202 pending+token）、`POST /api/mcp/confirm`。

## 3. LLM 多 provider（feat/llm-fallback）
- 主：opencode-go `deepseek-v4-flash`（`http://127.0.0.1:8788/inference/go/v1`，key 从 `OPENCODE_GO_API_KEY`）；备：Ollama `gemma4:31b-cloud`；
- 非流式整请求超时（`LLM_CHAT_TIMEOUT`），流式仅首 token 超时（15s/20s 可配），首 token 后不切换；
- 熔断：连续 3 次失败 → 60s 冷却 → 半开探测；`/api/health` 的 `providers` 字段逐 provider 展示状态。

## 4. 异步入库（feat/jobs）
- `src/ragm/jobs/store.py`：SQLite 任务表（queued/running/succeeded/failed/cancelled，attempts/next_run_at）；
- `src/ragm/jobs/runner.py`：单 worker 线程 + Event；重试退避 5/30/120s；启动 `recover()` 把 running 改回 queued；
- `max_attempts` 是总尝试次数：默认 4 = 1 次初始 + 3 次重试（不是“3 次重试”）；
- API：`POST /api/ingest`（202）、`GET /api/jobs/{id}`、`GET /api/jobs`、`POST /api/jobs/{id}/retry`（仅 failed）。
