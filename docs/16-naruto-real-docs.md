# 真实文档测试：火影忍者语料（扩充版，2026-11-01）

## 一、为什么不是"整本火影忍者小说"

1. **火影忍者是漫画/动画，不是小说**：原作是岸本齐史 1999–2014 年的漫画（700 话），没有一部"整本小说"；
2. **官方轻小说存在但受版权保护**：《卡卡西秘传》《鹿丸秘传》《鼬真传》《佐助真传》等是集英社出版的商业出版物，
   没有合法免费全文；从盗版站抓取不合适（也不稳定，站点基本都反爬/不可达）；
3. **更好的选择是百科/维基类内容**：信息密度高、可合法抓取、覆盖面广（人物/忍术/组织/剧情/设定），
   这也是本次扩充采用的方案；
4. 如果之后你**合法拥有**电子书（购买的 EPUB/PDF），本项目的 Unstructured 摄取链路可以直接吃（PDF/DOCX/EPUB → 切块 → 入库），
   不需要改代码。

## 三、端到端测试（18 题）

| 指标 | 第一版（12 题） | 扩充版（18 题） |
|---|---|---|
| 答案正确 | 12/12 = 1.000 | **16/18 = 0.889** |
| 引用全部有效 | 1.000 | **0.889** |
| p50 延迟 | 1,482ms | 1,382ms |

两条失败都是**如实拒答**（"资料中没有足够信息"），不是幻觉：

- "火影是什么职位？"：检索到了火影条目，但生成时判定证据不足（该条目偏"称号/角色"描述，缺"职位定义"的明确句子）；
- "忍者联军有多少人？"：语料里没有具体人数（十万白绝/八万联军这类数字未覆盖）。

正确样例（扩充版）：

## 四、结论

1. **语料扩充 3 倍后，链路依然稳定**：116 篇 / 791k 字，18 题正确率 0.889、引用有效率 0.889、p50 1.38s；
2. 失败模式是**拒答**而非编造，符合"证据不足就说不知道"的设计；
3. 语料规模上来后，检索覆盖明显变好（新增人物/忍术问题全部答对）；
4. 下一步可针对"职位定义/数字类"问题补充语料，或放宽生成阶段的拒答阈值。
